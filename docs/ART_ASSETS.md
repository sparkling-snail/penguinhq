# Art assets and visual identity

PenguinHQ is an independent portfolio project and is not affiliated with Disney or Club Penguin. The current character sprites are AI-generated fan art inspired by that game’s visual language; they are demonstration assets and are excluded from the MIT source-code license.

The new office background and social preview use PenguinHQ-specific signage, roles, architecture, and colors. They must not be represented as official Club Penguin art.

## Portfolio-safe replacement plan

Before commercial use or broad promotion:

1. Commission or generate an original character silhouette, face, clothing system, and walk cycle that do not reproduce recognizable franchise proportions or costume designs.
2. Replace every file under `apps/web/public/sprites/characters/` and preserve the documented four-direction sprite dimensions.
3. Record the creator, tool/model, prompt or brief, creation date, and usage rights for each replacement.
4. Run reverse-image and visual-similarity checks, then have a qualified reviewer assess trademark and copyright risk.
5. Update this file and `THIRD_PARTY_NOTICES.md` with final provenance.

This document is project hygiene, not legal advice.
