# 60-second portfolio demo script

Use this sequence to record a short, silent-friendly demo for the README and project page. Record at 1440×900 or 1920×1080 and export both MP4/WebM and a compressed GIF under 12 MB.

## Shot list

| Time | Action | On-screen point |
| ---: | --- | --- |
| 0–6s | Open the office, then expand **Portfolio tour**. | “A multi-agent AI system you can watch.” |
| 6–15s | Move Watty with WASD and click an agent. | The workspace is interactive, not a static illustration. |
| 15–28s | Open chat and run `/status` in a private local session. | Live state comes from the backend. |
| 28–40s | Trigger or replay a Job Hunter → Portfolio task. | One task ID links persistence, bus delivery, and the pigeon animation. |
| 40–51s | Open the Leetcode desk, edit a draft, request a hint. | Drafts and review attempts have separate persistence semantics. |
| 51–60s | Return to the office and show the source/case-study link. | Close on architecture and engineering depth. |

## Capture checklist

- Use sanitized demo data and a dedicated API key with a strict provider spending limit.
- Hide browser bookmarks, notifications, terminals, environment files, and personal account data.
- Keep the cursor still while labels are being read.
- Add captions; assume the viewer has audio muted.
- Show one complete interaction rather than fast-cutting through every feature.
- Review the exported frames for tokens, names, email addresses, and job-search data before publishing.

After recording, save assets as `docs/media/penguinhq-demo.webm` and `docs/media/penguinhq-demo.gif`, then place the GIF directly below the README hero image and link it to the higher-quality WebM.
